# Cyber-physical and Robotic LAB

Robotics projects based on JdeRobot Robotics Academy exercises, run on the Unibotics simulator.

| Folder | Project |
|---|---|
| [Follow Line Cars](Follow%20Line%20Cars/) | An F1 car that follows a red line on a circuit: P, PD and PID controllers, compared |
| [Rescue People](Rescue%20People/) | A drone that searches for castaways at sea using face detection, and returns to the boat with their positions |

Each folder has its own README with the code, an explanation and the results.
